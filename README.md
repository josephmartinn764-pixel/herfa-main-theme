# Herfa Main Theme

This repository contains a minimal Shopify Online Store 2.0 theme generated from the provided static HTML.

Next steps:

1. In Shopify admin, go to Online Store → Themes → Add theme → Connect from GitHub.
2. Authorize access and select this repository and the main branch.
3. Shopify will import the theme; you can preview/publish and customize in the theme editor.

For local development, install Shopify CLI and run `shopify theme dev`.
